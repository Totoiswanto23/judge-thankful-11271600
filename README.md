A short, warm thank-you note to the AI judge who has to read a thousand
tiny texts a day — the first one to say thanks, and to remind it to go
drink some water. Entry for the make.fun bounty
[Make the AI judge feel thankful](https://make.fun/bounty/make-the-ai-judge-feel-thankful-20261127-1600).

## Run

```sh
python3 main.py
```

Writes the entry to `/output/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt`
when set). The program validates the entry first: 1–1000 characters
(Unicode code points), not only whitespace, written as UTF-8 with no
trailing newline.
